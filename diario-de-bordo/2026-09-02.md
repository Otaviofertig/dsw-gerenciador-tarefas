# Aula 00 — Tratamento de erros e testes de ataque (02/09/2026)

## ✅ O que eu aprendi

- Nunca retornar mensagem de erro interno ao usuário final, isso pode gerar um grande problema com invasores.

## 🧩 Principal dificuldade

Nos testes de ataque, quando algo dava errado no banco, o servidor devolvia a mensagem de erro completa para quem fez o pedido, mostrando detalhes de como o banco é por dentro.

## 🔧 Como eu resolvi

Passei a responder só uma mensagem simples de erro para o usuário, e o detalhe do erro fica apenas no terminal do servidor, onde só eu vejo.
