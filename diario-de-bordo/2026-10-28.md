## O que aprendi

- Com o Tailwind, o visual muda só trocando classes no JSX. O botão do login ficou verde ao trocar `bg-blue-600` por `bg-emerald-600`. Depois usei o mesmo recurso para dar ao projeto um tema de caderno de estudos.
- Lacuna 1: faltava o `fetch` em `listarTarefas`. O `authHeaders()` envia o token, e sem ele a API responde 401.
- Lacuna 2: a função `criar` aceitava título em branco. Agora, se o título limpo tem menos de 3 letras, mostra o erro com `setErro` e dá `return`.
- Lacuna 3: o botão de trocar de modo está dentro do `<form>`, e um `<button>` sem `type` envia o formulário. Com `type="button"` ele só executa o `onClick`.
- Preciso de CORS? Em desenvolvimento sim, porque o Vite (`:5173`) e a API (`:3000`) são origens diferentes. Em produção não, porque o `server.ts` entrega a tela e a API na mesma origem.
- No `server.ts`, a ordem importa: primeiro o 404 em JSON para `/api/*`, depois o `express.static` e por último o SPA fallback. Se o fallback viesse antes, `GET /api/typo` devolveria o `index.html` com status 200.
- `localhost:5173` mostra o código ao vivo, mas `localhost:3000` entrega o build antigo até rodar `pnpm build:web`. Foi por isso que minhas mudanças "não apareciam".

### Erros que apareceram

| Erro | Causa | Solução |
| --- | --- | --- |
| `'tsx' não é reconhecido` | pasta sem `node_modules` | `pnpm install` na pasta |
| Build falhava com `Failed to resolve /assets/...` | o `index.html` da fonte era uma cópia do `dist` | apontar para `/src/main.tsx` e nunca editar o `dist` |
| `node_modules` e `dist` no `git status` | `.gitignore` com espaço antes de cada linha | tirar os espaços |
| Comentário `{/* */}` quebrava a tela | estava dentro da tag `<button ...>` | mover o comentário para fora da tag |
| `tsc` com erro TS1484 | o `tsconfig` do repositório exige `import { type ... }` | marcar os tipos com `type` |
| `ERR_PNPM_IGNORED_BUILDS` | o pnpm bloqueia scripts de instalação | `pnpm-workspace.yaml` com `allowBuilds` |

Ao mover o projeto para este repositório, o `FRONT_DIST` do `server.ts` passou a ser `../../app-react/web/dist`, porque API e front ficam em pastas diferentes.

## Perguntas do laboratório

**A.** O que acontece se usarmos uma variável comum em vez do `useState`?

> A tela não atualiza. A variável muda, mas o React não sabe que precisa redesenhar. O `useState` avisa o React a cada mudança.

**B.** Por que o formulário do Login recarregava a página, e como o `type="button"` resolveu?

> Todo `<button>` dentro de um `<form>` sem `type` envia o formulário, e o navegador recarrega a página. Com `type="button"` ele só executa o `onClick`.

**C.** Qual a principal vantagem do Tailwind em relação a um `.css` tradicional?

> O estilo fica junto do elemento, então para mudar a aparência eu só troco a classe, sem procurar em outro arquivo.
