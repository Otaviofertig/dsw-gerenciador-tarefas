# Equivalência CSS puro → Tailwind

Tabela de consulta das aulas 3 e 4. Para praticar, abra no navegador o [desafio do card responsivo](desafio-card-responsivo.html) e a [comparação CSS puro vs. Tailwind](css-puro-vs-tailwind.html). O Tailwind também é usado no [front React](../../app-react/README.md#web-front-end-conectado-à-api) e no [protótipo HTML](../../gerenciador-tarefas/README.md#protótipo-html).

| CSS puro | Tailwind |
| --- | --- |
| background | `bg-` |
| margin | `m-` |
| left | `ml-` |
| right | `mr-` |
| top | `mt-` |
| bottom | `mb-` |
| padding | `p-` |
| height | `h-` |
| width | `w-` |
